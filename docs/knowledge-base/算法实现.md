## 本仓库 Stage 0 工程约定（实现，不是改公式）

SFT 不写自定义 trainer。`scripts/train_sft.py` 读 `configs/vla/smolvla_sft.yaml`，校验三路 `512×512` LeRobot 集与本地 `smolvla_base`，再 `exec lerobot-train`。`scripts/train_sft.sh` 是唯一启动器：`--check` / `--smoke` 前台转发；正式 20k 步在 AutoDL 网页终端后台 `nohup setsid` 拉起（`ulimit -n 1048576`）。

- 无 GPU：`python scripts/train_sft.py --check` 或 `bash scripts/train_sft.sh --check`（只读 JSON/路径，不加载 VLA、不解码视频）。
- 有 GPU：短跑 `bash scripts/train_sft.sh --smoke`。正式 20000 步在 AutoDL **网页终端**执行 `bash scripts/train_sft.sh`（不要用 Cursor/Codex agent；启动器会拒绝 agent-owned 正式运行）。不抬 `ulimit -n` 时，sshd/PAM 的 1024 soft NOFILE 会让 torchcodec worker 报 `Errno 24`。2026-08-31 多次正式 run 的主因是 16 worker 使容器总内存增至约 120 GB 后 cgroup OOM，不是固定的 2000-step 训练问题。默认已改回 LeRobot 上游的 `num_workers=4`。冻结 vision encoder，只训 action expert（`train_expert_only=true`）。`eval_freq=0`：训练过程不启仿真；成功率评估另做。默认 `batch_size=32`。2026-08-31 的 1000-step 冒烟（`torchcodec`、不存 ckpt）确认 16 worker 时稳态瓶颈在 GPU 更新（`updt_s≈0.48 s`），不是解码（`data_s≈0.018 s`）；GPU 显存约 11.5 / 24 GB，但容器总内存在 1000 step 已达 106,582 MB。
- 视频解码：默认 `torchcodec`（`torchcodec==0.7.*` 对齐 `torch 2.8`）。`pyav` 是 LeRobot 保底（torchvision `VideoReader`，已弃用）。不要装 `torchcodec 0.10`：它对应 torch 2.10，在本环境会加载失败。
- W&B：`--wandb.enable=true`，project `smolvla-rltoken`。冒烟：`python scripts/train_sft.py --smoke`（2 步、`outputs/sft/peg_insertion_smoke`、不上传 model artifact）。正式训仍用 yaml 的 20000 步和 `outputs/sft/peg_insertion`。
- 相机：数据集 `environment_camera` / `hand_camera` / `insertion_camera` → 预训练 `camera1` / `camera2` / `camera3`（`--rename_map`）。state 9 维、action 8 维，由 SmolVLA 的 `max_state_dim` / `max_action_dim`（32）补零。
- Checkpoint：`outputs/sft/peg_insertion`。LeRobot 不允许覆盖已有目录；续训用 `--resume`。Stage 1 的 `--checkpoint` 指向 `outputs/sft/peg_insertion/checkpoints/last/pretrained_model`（不是 SFT 输出根目录）。last 尚未写出时，`--check` 可改用 `smolvla_base`。

## 本仓库 Stage 1 工程约定（实现，不是改公式）

- Hidden：冻结 SmolVLA 的 **VLM prefix 最终层 + RMSNorm**，不跑 action expert。`D=960`。
- PegInsertion 三路相机（`environment_camera` + `hand_camera` + `insertion_camera`），image-only 时 **`M≈192`**（每相机约 64 connector token）。默认丢掉语言和 state token。
- Encoder/Decoder：2 层、8 头、`d_model=512`，末尾 learnable `e_rl`，取最后一个位置为 \(z_{rl}\)。causal teacher forcing + `z.detach()`。Loss 是有效 token 上的 **masked mean-MSE**（与论文 \(\sum_i\|\cdot\|_2^2\) 差一个常数）。
- 训练：每 step **在线** VLA prefix forward，不写磁盘 embedding cache。相机与 SFT 同一套 rename（`environment_camera`/`hand_camera`/`insertion_camera` → `camera1/2/3`）。入口 `python scripts/train_rltoken.py`：YAML `configs/rlt/rl_token.yaml` 为真源；无 GPU 用 `--check`（不加载 VLA）。Checkpoint `outputs/rl_token/rl_token.pt` 含 encoder+decoder；Stage 2 只加载 encoder。`--checkpoint` 默认是 SFT `checkpoints/last/pretrained_model`。
- 不要用 Rajat 仓库的 noisy expert suffix 或 576 维 config。
- GPU 冒烟与正式 5000 步尚未跑（等 SFT 结束）。进度与未完成项：`docs/rltoken-training/适配进度与未完成工作.md`。
