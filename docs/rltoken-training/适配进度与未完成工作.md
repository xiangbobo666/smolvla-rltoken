## 1. 相对三个参考仓的取舍

| 决策 | 本仓库 | 跟谁 | 不用谁 |
| --- | --- | --- | --- |
| Hidden | 冻结 VLM prefix 最终层 + RMSNorm，`D=960`，不跑 action expert | afengleafs | Rajat 的 noisy expert suffix |
| Token | 默认 image-only，三路相机 connector，目标 `M=192` | afengleafs / 论文脚注 | rlt-openpi 全 prefix；Rajat 两路 hidden |
| Encoder | `Linear(960→512)` + 末尾 `e_rl` + learnable pos，取最后一位 | afengleafs | Rajat 的 576/256 与 4 层 |
| Decoder / loss | causal teacher forcing，`z.detach()`，masked mean-MSE | afengleafs、rlt-openpi | Rajat 共享 query、无 causal |
| 冻 VLA | `requires_grad_(False)` + extract `@torch.no_grad()` | 三仓默认 | rlt-openpi / afengleafs 的 `alpha L_vla`（SFT 已是 Stage 0） |
| 数据 | 每 step 在线 prefix forward，不写 embedding cache | 三仓都没有 cache | 计划原文里的磁盘 cache |
| 优化 | AdamW `lr=1e-4`，wd=0.01，clip=1，无 scheduler | afengleafs | Rajat cosine 退火到 0 |
| Checkpoint | 覆盖写 `outputs/rl_token/rl_token.pt`（encoder+decoder+config+step） | afengleafs | Rajat 按单 batch loss 存 best |
| 相机 | 与 SFT 同一套 `SFT_IMAGE_RENAME_MAP`（env/hand/insertion → camera1/2/3） | 本仓 SFT | afengleafs 改写 `input_features` 为数据集键 |

VLA 宽度以本地 `smolvla_base`（SmolVLM2，960）为准，不要用 Rajat README 里的 576。

## 2. 已完成

### 算法模块（本轮之前）

- `src/smolvla_rltoken/vla/extractor.py`：prefix-only 抽取。
- `src/smolvla_rltoken/rlt/module.py`：2 层 / 8 头 / `d_model=512`，causal teacher forcing。
- `tests/test_rl_token.py`：shape、causal mask、`z` 无梯度（纯 CPU）。

### 工程入口（本轮）

- 数据集 preprocessor 使用 `SFT_IMAGE_RENAME_MAP` + `rename_stats`，**不**把 policy 改成 `environment_camera`。`delta_timestamps` 仍用数据集键。
- `--checkpoint` 默认指向 SFT 的 LeRobot 目录：
  `outputs/sft/peg_insertion/checkpoints/last/pretrained_model`
  不是 `outputs/sft/peg_insertion`。last 还不存在时，`--check` 会提示改用 `smolvla_base`。
- YAML 为真源；CLI 只有显式传入才覆盖。
- CPU `--check`：只读 JSON/路径，不加载 VLA、不解码视频。
- W&B project `smolvla-rltoken`；正式训覆盖写 `outputs/rl_token/rl_token.pt`。
- 薄 CLI + `scripts/train_rltoken.sh`。`--smoke` 写入 `outputs/rl_token_smoke`，本轮未调用。
- CPU 测试：`tests/test_rl_token_train.py`（yaml、rename、delta timestamps、`--check`）。

## 3. 未完成 / 明确延后

- **GPU 冒烟**：未跑 `python scripts/train_rltoken.py --smoke`，未改也未跑 `tests/test_extractor_smoke.py`（仍是过时的两路 128 假数据）。真机 image-only 形状 `[B, 192, 960]` 尚未在本仓库 GPU 上确认。
- **正式 5000-step 训练**：等 SFT 写完 `checkpoints/last/pretrained_model` 且 4090 空闲。
- **Stage 2**：Actor / Critic / Replay / chunk env。Stage 1 的 decoder 进 RL 时不加载。
- **磁盘 embedding cache**：三仓都没有；本仓库继续在线 prefix forward。
- **KV cache 复用 reference action**：afengleafs 在抽取时 `use_cache=True` 给 Stage 2 用。本仓库 extractor 目前 `use_cache=False`，Stage 2 再加。
- **joint `alpha L_vla`**：不做。SFT 是独立 Stage 0（`train_expert_only=true`）。

## 4. SFT 结束后 GPU 上要跑的命令

conda 环境 `smolvla-rlt`。不要和正在跑的 SFT 抢 GPU。

```bash
# 确认 SFT last 已写出
ls outputs/sft/peg_insertion/checkpoints/last/pretrained_model/model.safetensors

python scripts/train_rltoken.py --check

# 可选：2 步短循环，不占正式输出目录
python scripts/train_rltoken.py --smoke

# 正式：5000 step → outputs/rl_token/rl_token.pt
python scripts/train_rltoken.py
# 或 bash scripts/train_rltoken.sh
```

若只想在 SFT 完成前测循环（image-only 的 VLM hidden 与 base 几乎相同，因为 SFT 冻了 VLM），把 checkpoint 指到 base：

```bash
python scripts/train_rltoken.py --smoke \
  --checkpoint /root/autodl-tmp/smolvla-rltoken/models/lerobot/smolvla_base
```

正式 Stage 1 仍应加载 SFT last，以便和 Stage 2 共用同一份 VLA。
